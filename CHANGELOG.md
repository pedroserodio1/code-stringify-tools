## [0.0.1] - 2026-02-12

### Added
- **Stringify (Replace Selection)**: Convert selected code to a JSON-escaped string and replace the selection
- **Stringify (Copy)**: Convert selected code to a JSON-escaped string and copy to clipboard
- **Destringify (Replace Selection)**: Convert an escaped JSON string back to normal code and replace the selection
- **Destringify (Copy)**: Convert an escaped JSON string back to normal code and copy to clipboard
- Context menu integration for quick access to all stringify/destringify operations
- Keyboard shortcut (`Ctrl+Shift+J` / `Cmd+Shift+J`) for fast stringify + copy workflow
- Support for JavaScript and JSON code conversion
